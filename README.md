# Kawaii World • Staff Management & Security Bot

Профессиональный многофункциональный Discord бот для управления персоналом сервера, многоуровневой иерархии должностей, системы выговоров и защиты сервера от несанкционированных действий (Anti-Abuse Guard).

---

## Архитектура проекта

```
kawaii_core/
```

## Установка и запуск

### 1. Установка зависимостей
Убедитесь, что у вас установлен Python 3.11 или новее:
```bash
pip install -r requirements.txt
```

### 2. Настройка токена
Создайте файл `.env` в корневой папке проекта на основе `.env.example`:
```env
DISCORD_BOT_TOKEN=ваш_токен_бота_здесь
```

### 3. Настройка прав бота в Discord Developer Portal
Для корректной работы бота включите следующие **Privileged Gateway Intents**:
- **Server Members Intent** (для отслеживания ролей и участников)
- **Message Content Intent**

Роль бота на сервере должна стоять **выше** всех ролей стаффа, которыми он должен управлять, и обладать правами:
- `Manage Roles` (Управление ролями)
- `Manage Channels` (Управление каналами)
- `View Audit Log` (Просмотр журнала аудита)
- `Send Messages`, `Embed Links`, `Attach Files`

### 4. Запуск (Локально или на хостинге)
```bash
python main.py
```
*(Также поддерживается запуск через `python3 main.py` на Linux серверах и Docker)*

## Реализованный функционал

### 1. Команда `/profile [ник]`
- Доступна только участникам с ролью Стаффа (`1524932407768383548`) или Владельцу.
- Если вызывается без параметров — открывает профиль вызвавшего.
- Отображает фирменный баннер (`profile_banner.jpg`), ветку, должность, активные выговоры (n/3), количество наказаний.
- **Интерактивные кнопки** (динамически отображаются только если доступны):
  - **Повысить** — повышает в рамках ветки на следующий ранг (с автоматической заменой ролей).
  - **Понизить** — понижает в рамках ветки на предыдущий ранг.
  - **Назначить** — доступно для пользователей без стаффа (Мастер назначает в свою ветку, Стафф Администратор/Владелец выбирает из меню).
  - **Снять** — снимает сотрудника со стаффа с подтверждением.
  - **Выдать выговор** — открывает модальное окно для ввода причины. Выговор выдается со сроком 14 дней. При 3/3 выговорах сотрудник автоматически снимается со стаффа.
  - **Снять выговор** — проверяет ранг выдавшего: если выговор выдал кто-то выше текущего проверяющего (например, Администратор), Мастер не сможет его снять (бот выдаст понятное предупреждение).
  - **Список выговоров** — выводит историю всех активных и архивных выговоров с точными датами и сроком истечения.

### 2. Команды выговоров
- `/warn add <сотрудник> <причина>`
- `/warn remove <сотрудник> [id]` (или алиас `/unwarn <сотрудник> [id]`)
- `/warn list [сотрудник]` (показывает личные выговоры или выговоры указанного сотрудника)
- **Фоновая задача (Background Task)**: каждые 10 минут проверяет выговоры с истекшим 14-дневным сроком и деактивирует их с отправкой лога.

### 3. Комплексная система защиты от вредоносных действий (Anti-Abuse Guard)
- Отслеживает абсолютно все критические действия на сервере:
  - **Выдача/снятие ролей через контекстное меню (ПКМ)**
  - **Редактирование ролей и их прав**
  - **Создание новых ролей** (бот мгновенно удаляет несанкционированную роль)
  - **Удаление ролей** (бот мгновенно воссоздаёт удалённую роль с прежними правами, цветом и параметрами)
  - **Бан участников** (бот мгновенно разбанивает пользователя)
  - **Кик участников** (бот фиксирует несанкционированный кик)
  - **Таймаут (мут) участников** (бот мгновенно снимает таймаут)
  - **Создание каналов и категорий** (бот мгновенно удаляет несанкционированный канал)
  - **Редактирование каналов** (бот фиксирует попытку изменения)
  - **Удаление каналов и категорий**
  - **Изменение настроек сервера** (название, иконка — бот откатывает назад)
  - **Управление вебхуками**
- Если у пользователя нет явного разрешения в боте:
  1. Бот мгновенно **откатывает действие** (разбанивает, воссоздаёт роль, удаляет канал, снимает мут, возвращает роли).
  2. Высылает нарушителю уведомление в ЛС: `Вы совершили запрещенное действие... Вам выдано замечание: X/5 Замечаний`.
  3. Отправляет подробный лог нарушения в канал `1553633570516377680`.
  4. При накоплении **5/5 Замечаний** снимает с пользователя все роли и выдает роль бана (`1553118613357990098`).

### 4. Команда `/permission <ник>`
- Доступна **строго** владельцу сервера (`1518844002533773362`).
- Открывает интерактивную панель с баннером (`permissions_banner.jpg`) и кнопками по категориям:
  - **Управление ролями**: Роли (ПКМ), Правка ролей, Создание ролей, Удаление ролей
  - **Модерация участников**: Бан участников, Кик участников, Мут/Таймаут
  - **Каналы**: Создание каналов, Правка каналов, Удаление каналов
  - **Сервер и интеграции**: Настройки сервера, Вебхуки
- Кнопки переключаются в реальном времени:
  - **Зеленый цвет** — право разрешено (защита не будет блокировать действие данного пользователя).
  - **Красный цвет** — право запрещено (защита откатит действие и выдаст замечание).
